# Завод металлообработки ООО «Уралгиб» (uralgib.ru)
## Высокопроизводительный веб-сайт под ключ (JAMstack / SSG)

Современный, молниеносный (PageSpeed 98–100) и высококонверсионный сайт промышленного производственного комплекса **ООО «Уралгиб»** (г. Берёзовский / Екатеринбург, Свердловская область).

---

### 1. Архитектура и стек
* **Архитектура:** JAMstack / Static Site Generation (SSG). 100% чистый статический стек без уязвимых CMS, MySQL и платных плагинов. Работает на любом традиционном хостинге (Beget, Timeweb, Reg.ru, Nginx, Apache) по принципу «залил файлы по FTP и готово».
* **Стилизация:** Скомпилированный и минифицированный Tailwind CSS (~38 КБ) с кастомной индустриальной палитрой (Industrial Titanium, Slate-950, Laser Amber, Steel Blue).
* **Скрипты:** Чистый современный Vanilla JS (без jQuery), разделенный на независимые модули.
* **Векторная графика (SVG):** Высокоточные схемы оборудования, изделий и кейсов с идеальной резкостью на 4K/Retina экранах без потерь качества и артефактов сжатия.
* **Offline / Double-Click Ready:** Полная поддержка относительных путей (`./` и `../`). Любая страница корректно открывается со всеми стилями и графикой как на веб-сервере, так и при простом двойном клике на `index.html` в Проводнике Windows (`file:///`).

### 3. Интерактивные модули
1. **Калькулятор стоимости металлообработки:**
   - Выбор операции (Лазер 6 кВт, Плазма, Рубка, Гибка).
   - Выбор металла (Черная сталь, Нержавейка, Алюминий, Медь/Латунь).
   - Ползунок толщины листа (0.5 – 20 мм) и быстрые кнопки.
   - Ввод длины реза (м.п.), врезок (шт), гибов (шт), порошковой окраски RAL (м²), КМД.
   - Мгновенный расчет ставки за метр и итоговой суммы с НДС 20%.
   - Кнопка фиксации сметы с передачей параметров в модальное окно заявки.
2. **Счетчики масштаба завода (как на lstk-ural.ru):**
   - «12+ лет на рынке», «500+ объектов», «6 000 Вт лазер», «220 тонн гибка до 4000 мм».
3. **Реализованные кейсы и объекты:**
   - Реальные контракты (склад 18×48м, шкафы 42U для ПАО «МОТИВ», лотки для АО «Уралкабель», ворота БКТП, торговый павильон, нержавеющая мебель) с городами, тоннажем и кнопкой «Рассчитать аналогичный объект».
4. **Собственное конструкторское бюро (КМ / КМД):**
   - 3D-моделирование деталей (Компас-3D, SolidWorks), оптимизация раскладки на листе с экономией 4–8% металла.
5. **Каталог продукции с Lightbox-галереей:**
   - 8 категорий изделий с фильтрацией по кнопкам и полноэкранным зумом.
6. **Умный поиск по ГОСТам:**
   - Живой поиск на страницах ГОСТ 19903, 19904, 24045, мгновенно фильтрующий строки по введенной толщине или ширине с подсчетом найденных позиций.
7. **Конверсионные элементы:**
   - Строгая компактная шапка без переносов строк.
   - Мобильная шторка (Drawer menu) для смартфонов.
   - Модальное окно с Drag-and-Drop загрузкой чертежей (DXF, DWG, PDF, STEP до 50 МБ).
   - Плавающая панель быстрой связи (WhatsApp, звонок, наверх).

```bash
npm run build

npm run test
```

### 5. Развертывание на хостинг
Для публикации сайта на Beget, Timeweb, Reg.ru или любом VPS:
* Скопируйте содержимое папки `dist/` (или корневые файлы проекта) в корневую веб-директорию хостинга (`public_html` или `www`).
* Файлы `.htaccess`, `robots.txt` и `sitemap.xml` уже преднастроены для мгновенной индексации.
